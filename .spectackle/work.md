## P-0065 proactive compact hint at 300 journal events + self-documenting generated config
kind: proposal
state: active
created: 2026-07-24
grilled: 2026-07-24

Requirement: the server must point out by itself when a compact is due (default threshold 300 journal events), and ship a global auto-generated config carrying all defaults. Current state (measured): compact.journal_max defaults to 500 in two places (defaultConfig() and the zero-block fallback in load()); the c-record is only produced by compactCandidates, which runs inside check and compact — so an agent that never calls check is never told, and this repo silently reached 506 events before anyone noticed. Design: (1) THRESHOLD 300 — change both default sites from 500 to 300; a config.yaml value keeps overriding it. (2) PROACTIVE HINT — postCall in internal/mcpserver/swarm.go already piggybacks sibling sw records onto ANY tool result; add the compact hint the same way so it reaches the agent regardless of which tool it called. It must be CHEAP and QUIET: do not read the journal on every call — evaluate at most once per debounced sync window, cache the count on the Server, and emit the hint AT MOST ONCE per threshold crossing (re-arm only after a compact runs or after the count grows by another threshold), so it never becomes per-call noise (respect the output-diet rejection R-0001). Record shape reuses the existing grammar: `c . journal <n> events since last compact`. (3) SELF-DOCUMENTING GENERATED CONFIG — EnsureScaffold writes .spectackle/config.yaml; make the generated file list every setting with its default value and a one-line comment (schema, ignore, ignore_regex, budget_default, compact.journal_max/done_max, swarm.lease_ttl/agent_ttl, feedback.max_rounds/grill, worktrees_dir), so a user can discover and tune everything without reading Go source. Existing config files must NOT be rewritten — only newly created ones get the full template. Exit criterion (explicit): defaults are 300 (unit test on defaultConfig and on the zero-block fallback); a fresh scaffold produces a config.yaml containing every key with its default and comments, and re-running EnsureScaffold on an existing config leaves it byte-identical; a server test proves the hint appears on an unrelated tool call once the journal exceeds the threshold and does NOT repeat on the next call; go test ./... -race green; lint 15/61/0. Rollback: revert. Scope: internal/workspace/workspace.go + test, internal/mcpserver/swarm.go + test, docs/lifecycle.md.
